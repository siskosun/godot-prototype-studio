# Code2Games 与现有原型闭环

核对日期：2026-10-07。核对对象：论文 v1、官方源码固定提交，以及当前工具的固定版本。没有重复评测论文，也没有据此修改三状态理论。

## 裁定

值得吸收的增量是一个可选、可执行的设计与源码映射。现有工具已能生成原型、执行检查、保留回放并按改动选择复测；缺口是把这些能力连接到稳定的对象和交互标识。新增实现放在 GPS 执行层，game-exp 的现有交接协议已够用。

论文在其十个固定提示、既定模型与评测条件下报告优势。这不足以证明所有快速原型任务的全局最佳工作流，也没有独立证明我们采用此映射后会节省多少时间。本次验证的是定位与复测协议的工程行为。

## 原始材料边界

论文第 3.1 节给出共享表示：目标、对象、交互规则，以及连接场景实现、引擎实现和可执行逻辑的持久标识。第 3.3 节用编译、运行和玩法反馈定位失败组件，局部修复后再执行。我们借用的是这条连接关系；不引入 Blender、UE5、四智能体架构或新的总理论。

官方公开源码提供结构化玩法计划、位置约束、placement_id / asset_id 对应和 Blender 实现报告。其当前主脚本输出 `.blend` 与视频，已核对的源码树没有论文所述的完整 UE5 重建与执行修复模块。论文方法与当前公开代码不能视为同一份完整、可直接复用的实现。因此新增代码为独立实现，没有复制其代码或增加其模型/资产服务依赖。

## 三项机制逐项映射

| 机制 | game-exp 1.5.0 | GPS 1.0.4 与现有生成流程 | 缺口及裁定 |
|---|---|---|---|
| 结构化中间表示 | Manifest、subject、scope、criteria、handoff 结构化地定义实验与工作边界 | brief / design_blueprint / mechanic_lab 描述玩法；prototype_contract 和 replay_trace 管实验问题与输入 | 实验合同和回放记录不是对象—交互设计表示。新增轻量 design_map，保留 brief 的验收权，不增加生成语言 |
| 持久对象对应 | subject.id、Candidate/source/build identity 识别项目与版本 | gameContent / testHarness 等哈希识别文件集合；资产 id、QA snapshot 识别部分资产或运行状态 | 项目、包、资产的标识没有自动连接设计对象、交互、负责源码与场景。新增稳定语义 ID 和源码锚点；仅静态对应，尚不验证运行时对象身份 |
| 执行反馈驱动局部修复 | Candidate / Rehearsal / trusted replay 检查固定产物；不是通用编辑器 | run_godot_checks 捕获错误；debugging 指导最小修复；change_impact 选择复测；QA bridge 支持场景和回放 | 反馈→设计对象→实现文件→原场景复测仍靠人工/智能体临时连接。新增失败标记或资源路径定位、源快照绑定和同命令复测检查；实际补丁仍由授权的源码编辑能力执行 |

H5 路由也已有目标/规则卡、状态观察、真实浏览器检查和“复现→最小修复→复测”流程。本次仅对已安装 H5 技能的相关指南做范围核对，没有审计其完整当前 GitHub 实现；没有宣称 H5 也已接入此 Godot 适配器。

## 已实现的最小增量

- `templates/design_map.json`：starter 的可运行示例；对象、交互、场景稳定 ID 与源锚点。
- `scripts/design_repair.py`：校验映射、定位执行失败、验证修复文件范围与同命令复测。
- `run_godot_checks.py --design-map`：执行前绑定映射及源码快照，保留完整日志并校验摘要，返回局部修复诊断。
- `init_workspace.py --design-map`：显式选择才生成记录；普通任务的默认流程不增加表单。
- 使用说明与条件触发入口：遇到反复定位、对象绑定混淆或多交互修改时使用；单点小修可跳过。

修复提示不扩大授权范围。未知错误、环境失败、过期报告、执行中源码变化均保持无法裁定。复测不能修改测试文件、换用通过型脚本或用冒烟替代原失败测试。文件范围检查无法确认同文件内是否还有无关修改，需要审查补丁。

## 验证

针对性回归覆盖映射失效、重复 ID、路径越界、未知/混合错误、环境失败、日志变化、旧源报告、修改测试文件、替换测试命令、缺失复测及跨基线变化。

真实引擎验证使用临时 Godot 4.4.1 样例：让移动动作提前返回 → 真实测试失败 → 定位到 move-player 与 game_model.gd → 仅恢复该文件 → 同一引擎、同一 import/test/smoke 命令通过 → 局部修复记录成立。没有修改用户项目、公开 playable 或实验状态。这个样例验证的是规则逻辑与协议，不是正常玩家输入、浏览器体验或研发效率。

最终 GPS 回归共 274 项：273 项通过，1 项原有的局域网 HTTPS 检查因当前环境到自动识别地址的网络不可达而失败。新增 24 项均通过，其中 1 项为上述真实引擎链路；该局域网失败在修改前的 250 项基线中也存在。game-exp 的 Conformance、盲比较及 Candidate 相关 28 项通过，其源码没有改动。运行时包已验证包含新增工具、模板和操作指南，并排除审计和测试目录。
