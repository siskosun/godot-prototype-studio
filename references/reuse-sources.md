# Reuse discovery sources

Use this list only when reuse could materially change the build decision. It is discovery guidance, not authority.

Search in this order:

1. user-provided repositories, existing local/internal prototypes, and project history;
2. official Godot demos and Asset Library entries that match the mechanic or technical need;
3. GitHub/GitLab source search using mechanic + Godot/GDScript terms;
4. optional community or model-generated-game indexes configured by the current environment.

Do not hard-code one model/vendor index as a permanent priority. Community indexes age quickly. If the host or project provides a current list of preferred indexes, use it as discovery input and then verify the original repository, revision, license, and runnable baseline.

Stars, model branding, or inclusion in an index do not establish quality or reuse suitability.
